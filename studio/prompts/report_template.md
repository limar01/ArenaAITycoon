# AGENT RETURN TEMPLATE (specialist → Zillion)

```
STATUS: DONE | DONE_WITH_CONCERNS | BLOCKED | FAILED
TASK: <AIT-<seq>>
IMPLEMENTATION: <what was done, approach>
FILES_CHANGED: <list with paths>
TESTS: <tests run (commands)>
TEST_RESULTS: <pass/fail counts + evidence paths/hashes>
KNOWN_RISKS: <honest list; NONE is a claim, verify first>
FOLLOW_UP: <next tickets suggested>
REVIEW_REQUIRED: YES | NO (Vanguard trigger)
```
Failures additionally carry: FAILURE/CAUSE/ATTEMPTED FIX/CURRENT STATE/RECOMMENDATION.
